# 🔐 Password Analyser

## About
Password Analyser is a beginner-friendly Python command-line project that evaluates password strength using basic security checks.

## Features
- Checks password length.
- Checks for uppercase and lowercase letters.
- Checks for numbers and special characters.
- Assigns a strength score and classifies passwords as weak, medium, or strong.
- Warns about selected common passwords.
- Provides suggestions to improve password strength.
- Warns about repeated characters and spaces.
- Allows repeated analysis until the user chooses to exit.

## Technologies Used
- Python
- Built-in Python string methods and functions

## What I Learned
- Using conditional statements and loops.
- Taking user input and displaying results.
- Using `any()` to check password characteristics.
- Working with lists, sets, and string methods.
- Applying basic password security concepts.

## Limitations
This is an educational project that uses simple rules and a small list of common passwords. Its strength rating is not a guarantee of password security.

## Project Status
Beginner cybersecurity project created while learning Python.

## Disclaimer
Do not enter real account passwords into this program. Use fictional test passwords for demonstrations.
